# Remake of Sui.io home page

For training purposes.

Remake: https://sui-shtyka.vercel.app/  </br>
Original website: https://www.sui.io/

### Tech stack

- Next.js 16 (App Router, SSG)
- React 19
- Motion (Framer Motion)
- GSAP
- Lodash

### Setup

Install:

```bash
npm i
```

Run:

```bash
npm run dev
```
